# FOSDEM2027
The website for the planned Open Hardware Devroom at FOSDEM'27:
https://openhardwaredevroom.github.io/FOSDEM2027/

The call for participation has not been announced yet, but the dates
for FOSDEM'27 have been [announced](https://fosdem.org/2027/news/2026-08-30-fosdem-2027-dates/): it will be held 30 & 31 January, 2027,
at [the usual location](https://www.openstreetmap.org/relation/13699100#map=18/50.812322/4.382113).
